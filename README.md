# DWARF · Guía Virtual

Guía web para jugar **DWARF** (juego de rol solitario de Tavern Lore):

1. **Personaje:** asistente paso a paso (trasfondo, nombre, rasgo, atributos 3d6 repitiendo 1 y 2, PV, oro, armadura, arma, suministros, estación y terreno).
2. **Guía de turnos:** primero pide las características del personaje (modificadores) y luego recorre el procedimiento diario: clima → ración → por hexágono terreno, punto de interés y encuentro → forrajeo/caza/pesca → campamento y encuentro nocturno.
   En cada paso indica **qué dado tirar**, pide el **resultado**, muestra **la tabla consultada** con la fila resaltada y propone el siguiente paso.
   Incluye combate completo (iniciativa, ataque, defensa, críticos, pifias, moral, huida, heridas y muerte, botín), mazmorras, asentamientos, PNJ, rumores, pergaminos, objetos mágicos y subida de nivel.

Puedes tirar tus dados reales o pulsar «Tirar por mí». La partida se guarda en el navegador (localStorage); usa *Exportar/Importar* en Inicio para pasarla a otro dispositivo.
